Pre-light-theme / halftone redesign backup
Created: 2026-11-14

These are byte-for-byte copies of the three report HTML files before the requested light-theme/color/halftone refresh.
To restore one, copy it over the corresponding file in ../../ (the hh/benchmarks directory):
  cp report.html ../../report.html
  cp report-repeat.html ../../report-repeat.html
  cp report-repeat-grow.html ../../report-repeat-grow.html

The reports are self-contained; keep this backup directory intact if you may want to undo the refresh.
