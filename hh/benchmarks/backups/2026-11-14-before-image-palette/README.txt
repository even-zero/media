Pre-reference-palette / stripe-halftone backup
Created: 2026-11-14

These are byte-for-byte copies of the report HTML files before applying the attached mint/forest palette and replacing the dotted texture with a stripe-screen halftone treatment.
From this directory, restore the previous versions with:
  cp report.html ../../report.html
  cp report-repeat.html ../../report-repeat.html
  cp report-repeat-grow.html ../../report-repeat-grow.html

Keep this folder intact if you may want to undo that refresh.
